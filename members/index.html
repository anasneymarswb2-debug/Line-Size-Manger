Membership and terms

Line Sizing Manager is free. The Control Valve Sizing Manager and the process flowsheet are for members: what is included, how to get an access code and the terms of use.

By Muhammad Anas, process design engineer · updated 2026-11-07 · version 2026.11.8.9

Free for everyone

Line Sizing Manager stays free: liquid, gas, steam and two-phase line sizing, relief lines, wall thickness, heat loss, Excel and PDF line lists, the guides and the full validation report. No account and no sign-up.

Each members tool is licensed separately: a flowsheet code opens the flowsheet only, a valve code the valve tool only.

How to get access

  1. Send a message on LinkedIn with your name, company and which tool you need (valve tool, flowsheet or both).
  2. You receive a personal access code (format XXXX-XXXX-XXXX-XXXX-XXXX) with its expiry date.
  3. Open the valve tool or the flowsheet, enter the code and tick “Remember on this device” if it is your own computer.
Only Line Sizing Manager is free. The members tools are available by access code only.

Terms of use

  • Personal code. A code is for the person or company it was issued to. Do not share or publish it: codes can be withdrawn, and every update issues a new content key, so a withdrawn or expired code stops working.
  • Engineering responsibility. The tools are for preliminary engineering, checking and learning. Results must be reviewed by a qualified engineer and confirmed against the project specification, licensor requirements and vendor data before use in design, purchasing or operation. No warranty is given; the author is not liable for decisions made with the results.
  • Your data stays with you. Everything runs in your browser. Cases, projects and flowsheets are kept only on your device and in files you save; nothing is uploaded and there is no tracking.
  • Renewal. Before a code expires, ask for a renewal on LinkedIn; the same code is extended and your saved projects keep working.
  • Security. The members pages are encrypted (AES-256-GCM, PBKDF2 key derivation) and open only with a valid code. Report a security concern through the security contact.

How the checks work

Every result the calculators produce is compared with an independent reference: the CoolProp property library (reference equations of state), the fluids and ht engineering libraries, published standard examples, and hand calculations. The same checks run inside the calculator every time it opens (Validation tab), so this page is simply that table, extracted from the current build (version 2026.11.8.3). A check passes when the deviation is inside its tolerance; the tolerance reflects the accuracy of the method, not the convenience of the result.

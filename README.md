# Line Sizing Manager — web edition

Free browser-based line sizing calculator for process plants: liquid, gas & steam, two-phase (API RP 14E), control valves (IEC 60534-2-1), PSV inlet/outlet lines (API 520 Part II / API 521) and ASME B31.3 wall thickness.

**Website:** https://anasneymarswb2-debug.github.io/Line-Size-Manger/
